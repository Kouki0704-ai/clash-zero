# CLASH ZERO

近接アクション対戦ゲーム「CLASH ZERO」の開発リポジトリ。

## 現在の内容

- ロビー画面とコジュの2Dアイコン・3D風プレビュー
- VS A.I.練習モード（コジュの仮ステータス、移動・攻撃・ダッシュ、追跡して反撃するAI）
- Colyseusによる2人用ルーム作成・ルームコード参加のサーバー基盤

コジュの性能値は初回プレイテスト用の仮設定。オンラインルームは作成・参加できますが、キャラクターの移動や攻撃の同期は未実装です。

## ローカルで動かす

必要環境：Node.js 22以上、npm

1. ターミナルを開き、クライアントを起動する。

	```sh
	cd client
	npm install
	npm run dev
	```

2. ブラウザーでViteが表示するURLを開く。

VS A.I.はフロントエンドだけで試せます。ルームを作成・参加するには、別のターミナルでサーバーも起動します。

```sh
cd server
npm install
npm start
```

## 公開について

このリポジトリをGitHubに公開しても、ゲームを遊べるWebサイトやオンラインサーバーが自動で公開されるわけではありません。Web画面はGitHub Pagesなどへ、Colyseusサーバーは別のホスティング先へ公開する必要があります。
